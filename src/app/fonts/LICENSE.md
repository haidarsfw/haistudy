# Fonts

Self-hosted copies of the latin subset served by Google Fonts, used by
`src/app/layout.tsx` through `next/font/local`.

| File | Family | Used as | Source |
|---|---|---|---|
| `onest-latin-wght.woff2` | Onest (variable, 400-800) | headings | fonts.google.com/specimen/Onest |
| `golos-text-latin-wght.woff2` | Golos Text (variable, 400-800) | body text | fonts.google.com/specimen/Golos+Text |
| `jetbrains-mono-latin-wght.woff2` | JetBrains Mono (variable, 400-700) | timers, keys, links; Settings pick | fonts.google.com/specimen/JetBrains+Mono |
| `plus-jakarta-sans-latin-wght.woff2` | Plus Jakarta Sans (variable, 500-700) | Settings pick | fonts.google.com/specimen/Plus+Jakarta+Sans |
| `inter-latin-wght.woff2` | Inter (variable, 400-700) | Settings pick | fonts.google.com/specimen/Inter |
| `poppins-latin-{400,600,700}.woff2` | Poppins | Settings pick | fonts.google.com/specimen/Poppins |
| `quicksand-latin-wght.woff2` | Quicksand (variable, 400-700) | Settings pick | fonts.google.com/specimen/Quicksand |
| `lora-latin-wght{,-italic}.woff2` | Lora (variable, 400-700, roman and italic) | Settings pick | fonts.google.com/specimen/Lora |
| `merriweather-latin-wght{,-italic}.woff2` | Merriweather (variable, 400-700, roman and italic) | Settings pick | fonts.google.com/specimen/Merriweather |
